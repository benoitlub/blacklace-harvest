# Blacklace Harvest

Petit site statique destiné à accueillir des pages proposées par Publisher.
La présence de la page d'accueil ne prouve pas qu'un circuit autonome de récolte
est actif.

Le déploiement est assuré par `.github/workflows/pages.yml` sur un push vers
`main` ou un lancement manuel. La configuration d'environnement Pages appartient
au job de déploiement, pas à la racine du workflow.

Le système Gérard actuellement maintenu se trouve dans
[poulpe-fiction](https://github.com/benoitlub/poulpe-fiction) et
[blacklace-publisher-ai](https://github.com/benoitlub/blacklace-publisher-ai).
